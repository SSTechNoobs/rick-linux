# Ricks Linux ISO

This directory contains the reproducible build recipe for the Ricks Linux live installer ISO.

## Build

Run: ./iso/build-iso.sh

Output directory: ~/Downloads/ricks-linux-v1.0.0/

Live USB installer command: rick-install
